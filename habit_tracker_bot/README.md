# 🎯 Habit Tracker Telegram Bot

Асинхронный Telegram-бот для отслеживания и формирования полезных привычек. 
Спроектирован с использованием современности веб-стека Python.

## 🛠 Стек технологий
* **Python 3.10+**
* **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
* **SQLAlchemy 2.0 (AsyncORM)** — ORM для работы с базой данных
* **SQLite / aiosqlite** — асинхронная реляционная БД

## 🚀 Функционал
- 👤 Автоматическая регистрация пользователей в системе
- ➕ Добавление новых привычек с валидацией ввода
- 📋 Просмотр текущего списка привычек
- ⚡ Асинхронная обработка всех запросов
